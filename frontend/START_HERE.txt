BurnCal frontend handoff — 14 November 2026

This archive contains the current frontend source, including the latest anomaly UI changes, package-lock, assets, tests and documentation. No backend or real observation data is included.

1. Install Node.js 22.13+ on branch 22, or 24+, and npm 10+.
2. Extract the ZIP, then open a terminal in the frontend folder.
3. Run: npm ci
4. Run: npm run dev
5. Open http://127.0.0.1:5173

For a standalone UI preview, choose Data connection -> Synthetic demo, Source demo, then Run source demo. Harmonization and anomalies are not generated by the synthetic demo.

API mode expects the team's backend at http://127.0.0.1:8000. To change it, copy .env.example to .env.local, update VITE_API_BASE_URL, and restart Vite. All VITE_ values are public browser configuration, never secrets. An absent backend shows an error; the current team backend may still return explicitly marked placeholders.

Checks: npm run check
Browser suite: npx playwright install chromium, then npm run test:e2e
